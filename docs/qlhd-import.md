# 群狼环鼎（qlhd）实体卡自动录入说明

本文件说明**本轮由实体卡照片自动录入**的数据范围、如何启动本地管理页审查修改，
以及仍然需要人工核对的地方。

数据源目录（唯一权威源）：`data/`；SQLite（`build/sgs.db`）只是由 YAML 全量重建的生成物。

---

## 1. 启动本地管理页（审查 / 修改）

```bash
cd /data/wf/1002/sgs-helper

# 依赖（本机 py311 环境已装：fastapi / uvicorn / jinja2 / python-multipart）
/data/c60060534/miniconda3/envs/py311/bin/python scripts/admin.py --port 8000
# 或者：
# uvicorn sgs_helper.admin.app:app --host 127.0.0.1 --port 8000
```

浏览器打开 <http://127.0.0.1:8000>：

| 想去哪 | 地址 |
| --- | --- |
| 首页（统一搜索 + 数据量 + 校验结果） | `/` |
| 武将列表 | `/list/general` |
| 武将版本 | `/list/general_variant` |
| 实体卡印刷（游戏牌） | `/list/card_printing` |
| 技能版本 | `/list/skill_version` |
| 待核验清单 | `/review` |

常用页面上的内容：

- **武将详情页**：`/view/general/<id>` —— 每个「国战版 / 国战·晋 / 国战·君主」版本都会显示
  **称号、势力、体力（阴阳鱼）、编号（卡面原样，如 `G.WEI 075`）、画师、卡图**，
  以及该版本的技能与绑定的技能版本文本。
- **实体卡详情页**：`/view/card_printing/<id>` —— 显示**整张卡图**、花色点数、角标、画师、
  牌堆、卡面文本。
- 编辑任意一条：详情页右上「编辑」；武将「+ 新增版本」可以给同一个武将再加版本。

> 管理页**不会**直接改 SQLite。固定流程是
> `浏览器编辑 → 写回 YAML → validate → build_db → SQLite 更新`，
> 任何一步校验失败都一个字都不落盘。

### 重建数据库 / 校验

```bash
DATA=/data/c60060534/miniconda3/envs/py311/bin/python
$DATA scripts/validate_data.py     # 0 错误 / 48 警告（见下）
$DATA scripts/build_db.py          # 重建 build/sgs.db
$DATA scripts/query.py general 蒋干
$DATA scripts/query.py stats
```

## 3. 识别是怎么做的

**卡面上的全部文字都只用 PaddleOCR 官方 API 跑，并以 Paddle 的结果为准**（不再用其它 OCR / VLM 覆盖）：

| 字段 | Paddle 来源 |
| --- | --- |
| 称号 | **PP-OCRv6** 整卡 OCR 上半部的短竖排行（与武将名同一列时按位置切开） |
| 技能名 + 技能说明 | **PP-OCRv6** 的带坐标文本行：下部「左侧短行 = 技能名，右侧长行 = 该技能说明」逐条还原 |
| 游戏牌牌名 / 卡面文本 | **PP-OCRv6** |
| 画师 | **PP-OCRv6** 底部版权行 `©…Illustration: XXX` |
| 编号 | **PP-OCRv6** 右下角 `G.WEI 075` |

- 整卡 OCR 用的是 `PP-OCRv6`（405 张全部跑完，含 236 张底边放大补漏）。
- 技能说明**以卡面文本为准**：本产品 290 条技能版本中，与 WIKI 国战文本能对上的有 155 条，
  其中**只有 13 条与 WIKI 相同，142 条是卡面自己的文字**（这批卡是国战版/做过平衡调整）。
- `PaddleOCR-VL-1.6` 也接好了（能读竖排艺术字），但评测期间该服务明显降级：同一张图时好时坏、
  大量空返回、单张要 100s+ 排队，因此**没有**把它作为最终来源；服务恢复后可用同一套脚本重跑升级。
- 卡牌切分用 OpenCV 网格/接缝（这些图是黑底卡牌拼图，卡与卡紧贴、无透视旋转）。
- **势力以卡面为准**：① 卡面编号前缀（`G.WEI`→魏、`G.JIN`→晋、双势力 `G.WEI/SHU`→「魏/蜀」）；
  ② PP-OCR 读到的左上角势力字；③ 首轮读法；④ 最后才用三国杀 WIKI。注意 WIKI 的「势力」是
  **身份局**势力，国战势力会不同（如 王濬/文鸯/杜预 国战是晋，WIKI 写魏/群）。
- 性别 / 阴阳鱼体力 / 武将牌系列来自三国杀 WIKI 的「国战版本」小节（这些不是卡面文字：
  体力是阴阳鱼图标数量，脚本不数图标）。
- **双将牌**（`颜良&文丑`、`张昭&张纮`、`陈武&董袭`、`崔琰&毛玠`、`蒋琬&费祎`、`李傕&郭汜`、
  `张虎&乐綝`、`糜芳&傅士仁`）：登记成**一个 General**（名字就带 `&`）+ 一个国战版 variant，不拆成两个武将。
- **双势力牌**（孟达 魏/蜀、夏侯霸 蜀/魏、张鲁 群/魏、文钦 魏/吴、苏飞 吴/群、潘濬 吴/蜀、
  刘琦 群/蜀、彭羕 蜀/群、士燮 群/吴、许攸 群/魏、糜芳&傅士仁 蜀/吴）：同样是一个 General + 一个
  variant，`faction` 直接写成「魏/蜀」这样的双值（字段本身是自由文本，不需要改 schema）。

## 3.5 指示物卡牌（无花色、非武将也非游戏牌）

有一批卡**没有花色、没有点数**，也不是武将牌／普通游戏牌，统一归到「**指示物**」：

| 卡 | 说明 |
| --- | --- |
| 军令 ×6 | 卡面只有盾形“军”字令牌 + 效果文字，是**衍生指示物** |
| 纵横 ×3 | 《纵横捭阖》的**衍生技能牌**，卡面只印系列名与一个衍生技 |
| 五虎将大旗 ×1 | 角标「陣」 |
| 八荒死士令 / 不进则退 / 赋礼 / 祸起 / 激励 / 落石 / 胜者为王 ×7 | 九变篇的指令牌，文字都是 `◇/◆` 开头的全局效果 |
| 黄巾天兵符（角标 勢） / 缘江烽火图（角标 變） ×2 | 原来误判成「装备/宝物」，卡面其实**没有**任何 `装备/宝物/锦囊` 类型标签，编号同属 `G.EMA` 家族 |
| 五子良将纛（原误登记为武将「五子良将」）×1 | PP-OCR 把「纛」读成「蠢」；它和「五虎将大旗」是一对，是**旗帜类指示物**，不是武将 |

共 **20 张实体卡 / 12 个卡牌定义**。处理方式：

- `CardDefinition.card_type` = `other`、`subtype` = `指示物`；
- `CardPrinting.card_set` = `指示物`（产品 `qlhd` 的 `card_sets` 里也加了这一项）；
- `suit` = `none`、`rank` = `null`（它们本来就没有固定字段）；
- 卡牌列表可以按「牌堆 = 指示物」筛出来：`/list/card_printing?package=指示物`；
- 原来有牌堆归属的（军令来自势备篇）写进了该条的 `notes`。

**判定依据**：三国杀卡面左下角会印类型标签（如 诏书 印 `裝備/寶物`、明光铠 印 `装备/防具`）。
这两张的 PP-OCR 全文里**没有**这类标签，说明它们本来就不是普通游戏牌；
再结合编号同属 `G.EMA`（= 指示物家族），所以归入指示物。

## 4. 还需要人工核对的点

1. **称号（最需要人工核对）**：群狼环鼎把称号印成**竖排艺术字**，Paddle 对它的识别率不高。
   当前 164 条国战版本里 153 条有称号，全部是 Paddle 的读数；其中 108 条在 `notes` 里同时写了
   三国杀 WIKI 的称号与逐位相同字数，供你对照卡图判断（例如 蒋干：Paddle 读「絹摘悬信」、
   WIKI 为「锋镝悬信」）。**建议按 notes 抽查修正。**
2. **48 条「同一产品同花色点数」警告**：国战是多个牌堆混装（国战标准 / 势备篇 / 九变篇 /
   不臣篇 / 君临天下各包 / 纵横捭阖），同一花色点数在不同牌堆里重复是正常的；
   但部分卡的右下角角标 OCR 成了「周 / R」等，没能映射到具体牌堆，所以这 48 条无法进一步区分。
3. **军令牌**：6 张「军令」卡面只有盾形“军”字令牌与效果文字，没有牌名，统一登记为
   `card_jun_ling_*`，`card_set` 记为 **势备篇**，并用效果文字区分；它们本质是**衍生指示物**。
4. **《纵横》3 张卡**：卡面顶部只印系列名「纵横」、没有武将名，登记为 `card_zong_heng_*`
   （衍生技能牌），技能文本已完整记录。
5. **技能文本**：优先用三国杀 WIKI 的国战版本原文；WIKI 没有国战段落的（主要是晋 / 野心家武将）
   用卡面 OCR 文本，可能有小错。
6. **编号**：已按卡面原样保存（`G.WEI 075`、`G.WEI/SHU 079`、`G.EM 005` 等）；
   `NUMBER_PATTERN` 已放宽到允许 `.` `/` `&` 和空格。
7. **14 条告警**：`胆守`、`蛊惑`、`护驾`、`化身`、`激将`、`七星`、`潜心`、`求援`、`肉林`、
   `陷嗣`、`谮毁`、`制霸`、`忠勇`、`咒缚` 这 14 个技能原本只被 FAQ 引用、没有被本批卡片使用；
   删除它们的技能版本后，它们的技能本体被 FAQ 引用着不能删，于是会保留 14 条
   「技能本体没有任何 SkillVersion」的告警。其余 48 条告警仍是「同产品同花色点数」。

## 4.5 字段口径（本批已定）

- **别名（aliases）已彻底删除**：模型 / DB 列 / 管理页字段与标签 / YAML / 测试 / 模板全部清掉，
  保存后不会再写回。
- **势力以卡面编号为准**：`G.WEI/SHU` → 「魏/蜀」（双势力存成一个字符串，读取时按
  `/ 空格 、 , |` 拆 token，所以小程序按任一势力都能筛出来）；**`G.AM` → 「野心家」**；
  **君主牌 `G.EM` 按卡面自己的势力**（孙权君主牌＝吴，和其他君主牌一样）。
  编辑时用空格 / 斜杠 / 顿号 / 逗号分隔都可以，保存时统一归一化成「魏/蜀」。
- **版本标签统一写「群狼环鼎」**；君主牌写「群狼环鼎·君主」（和孙权一致）；
  只有同一武将有第二张同标签的卡时才加后缀（现在是司马懿/羊昭/羊祜的晋牌 =「群狼环鼎·晋」）。
- **技能版本标签只显示一次**：版本标签与产品名重复时不再重复显示
  （下拉是「国战 · 群狼环鼎 · 技能文本」）。
- **画师**可在武将编辑页直接填；**珠联璧合**是新的多值字段 `zhulianbihe`，
  可写多个武将，也支持类别值（卡面原文：贾南风＝「男性武将」、张角＝「群势力武将」、
  司马懿(君主) ＝「晋势力武将」、刘备(君主) ＝「蜀势力武将」）。
- **指示物卡牌**（无花色）共 20 张：军令×6、纵横×3、五虎将大旗、五子良将纛、八荒死士令、
  不进则退、赋礼、祸起、激励、落石、胜者为王、黄巾天兵符、缘江烽火图。
- **诏书**：卡面左下角印的是「裝備/寶物」→ 已从普通锦囊改成 装备·宝物。

## 4.6 核验状态（改成一个复选框）

- `General`（武将个体）**本身没有核验状态字段**——之前「武将列表」全都显示未核验、
  「武将版本列表」显示已核验，就是因为两边读的东西不一样。
- 现在**武将的状态由它的版本推导**：取最保守的那个（`unverified < conflict < community
  < official < physical_verified`），列表徽章、状态筛选、`/review` 汇总都用这个派生值，
  两个列表显示的永远一致。
- 武将编辑页把原来的「核验状态」下拉换成**一个复选框**：勾上 = 实体卡已核验
  （`physical_verified`），不勾 = 未核验。（用「复选框 + 同名 hidden」保证不勾时也会提交。）
- 武将版本列表里**点名字就直接进编辑页**（列表右侧另有「看武将」）。

## 4.7 武将牌系列做成独立实体（带层级）

- 新增实体 `general_set`（目录 `data/general_sets/`，共 14 个），字段：
  `id / name / parent_id / product_id / sort_order / notes / source / verification_status`。
- **层级靠 `parent_id`**，武将版本只写**最具体**的那个：

  ```
  君临天下            （顶层）
  ├── 君临天下·阵     parent_id = set_jun_lin_tian_xia
  ├── 君临天下·势
  ├── 君临天下·变     ← 孙权君主牌就写 general_set: 君临天下·变
  └── 君临天下·权

  不臣篇              （顶层）
  ├── 不臣篇·上
  └── 不臣篇·下
  ```

- 系统能顺着 `parent_id` 推出上层（不用在武将上重复写）：孙权那张显示成
  「系列 君临天下·变（君临天下）」；系列列表按「上级 + sort_order」排序；
  系列详情页显示上级、子系列、以及**所有在用它的武将版本**（可点进去直接编辑）。
- 校验：武将版本写的系列名、产品声明的系列名，都必须有对应的 `general_set` 实体，
  否则告警（当前 0 条）。
- 编辑页「武将牌系列」下拉会显示层级（「属于 君临天下」「子系列 不臣篇·上、不臣篇·下」），
  且**产品声明过但还没有卡在用的系列也能选到**（显示已用 0 次）。

## 5. 管理页的几处定制

- **武将列表 / 武将页按编号排序**（`G.AM 001 → G.WEI 089`），筛选前后一致；
- **势力筛选**除魏/蜀/吴/群/晋外，还把编号前缀里的 **野心家**（G.AM）与 **君主**（G.EM）做成可筛选值；
- 武将版本列表里的「编辑」直接跳到专用录入页（`/edit/general/<general_id>?variant=<id>`）；
- **武将编辑页显示卡图**（右侧悬浮预览 + 画师/编号），并把技能版本标签与产品名重复的部分去掉，
  技能版本下拉现在只显示两个前缀：`国战 · 群狼环鼎 · 技能文本`；
- 武将编辑页每个技能下多了「✎ 查看 / 修改这个技能版本的描述」，**可原页内直接改技能描述**，
  保存时就地更新那条 SkillVersion（不新建版本）；
- 另有 **`/ocr` 子页面**：粘贴截图或选一张已录入卡图，用 PaddleOCR 官方令牌试跑
  PP-OCRv6 / PaddleOCR-VL 等模型，直接看逐行文本、置信度和原始 JSON。
