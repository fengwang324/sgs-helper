# 用户图鉴

根目录 `index.html` 是当前用户入口。页面使用本次人工复核后的全部资料，沿用原 Wiki 的分类浏览方式，默认进入武将索引。可以直接用浏览器打开本地文件，也可以放在静态网站空间；运行时只加载本地 HTML、CSS、JavaScript 与卡图，没有接口、登录、编辑入口或后端依赖。

## 查阅

- 武将按编号、称号独立收录；同名武将分别显示，不合并。顶部搜索支持姓名、编号、称号或技能正文；武将索引提供吴、蜀、魏、群、野、晋六个势力按钮，重复点击选中项取消筛选。双势力匹配任一势力，统一排在单势力之后；单势力按完整编号的字母数字顺序，双势力内部按尾部编号数值排序。列表仅显示姓名、称号与势力图片，不显示编号或卡包；技能详情的武将卡片沿用相同形式。
- 武将详情显示牌面、势力、体力、性别、称号、编号、画师、珠联璧合及全部自带技能。
- 技能正文中已收录的技能名、卡名可点击，在弹窗中查看说明；可继续查阅完整条目。关闭弹窗后保留武将位置。单字卡名仅在书名号、引号或方括号内识别，避免将“杀死”等普通用词当成卡名；“连环状态/传导”等规则措辞不识别为连环技能。
- 君主首技能中的五虎将大旗、黄巾天兵符、缘江烽火图、五子良将纛、八荒死士令均可点击，显示指示物卡图及效果，并可进入完整指示物条目。武将页下方另列“关联指示物”，游戏牌及君主装备继续列于“关联卡牌”；指示物效果中已收录的技能/卡牌也可继续点击。
- 正文引用的其他技能附在“关联技能”中，以 `*` 标明并注明引用来源。此列表可以递归查找、去重，不改变武将的技能绑定，不将补充说明作为其自带技能。
- 武将自带技能优先使用其绑定的技能版本；关联技能按玩法及产品选择唯一匹配版本。有歧义时不任意选取文本，完整条目列出已收录版本供查阅。
- 游戏牌索引以卡图展示，按基本牌、锦囊牌、装备牌以及各自牌族分组，同组内按拼音排列，可按二级分类和三级类型筛选。详情显示效果、使用方法、武器攻击范围和非空备注；牌堆信息暂时隐藏，数据库中的原字段保留。指示物单列。
- 技能、指示物、关键词与FAQ按名称/问题的拼音排列，忽略开头括号或引号。FAQ与关键词均点击展开；FAQ保留来源。顶部搜索检索武将、技能、卡牌、关键词及 FAQ，按 `/` 可聚焦搜索框。产品入口显示年份、玩法、武将牌组及游戏牌拓展包，武将牌组仅展示名称。
- 手机端为四列两行分类导航、两列卡图与单列详情；桌面端自动显示侧栏与多列索引。长姓名及双势力图标分行，称号允许完整换行。返回已访问页面时保留该路由的滚动位置以及FAQ/关键词展开项。

关联 FAQ 按问题/答案中出现的武将名或技能名匹配；这属于阅读索引，不额外生成裁定或补写规则。正文从数据库读取；红桃、方块渲染为红色花色图标，黑桃、梅花为黑色，原Unicode字符仍保留在源数据。锁定技、限定技、阵法技、主将技、副将技可点击查看关键词说明；君主技按原文显示。阵法技的队列、围攻、阵法召唤说明从各自关键词派生，避免重复维护。四张已确认可重铸的锦囊以标签展示，详情标签可点开通用重铸说明。关键词气泡在可见视窗内定位，长内容可滚动，支持关闭按钮、再次点击触发词、点击外部和Escape；弹窗内先关闭气泡，再关闭关联弹窗。

## 维护与生成

YAML 仍是唯一权威数据源。修改源数据后，在仓库根目录执行：

```bash
python scripts/validate_data.py --strict
python scripts/build_db.py
python scripts/build_frontend.py
```

导出脚本先完整校验数据，再生成 `web/catalog.json` 和 `web/catalog.js`。JSON 便于人工核对；页面通过普通脚本标签读取同内容的 JS，因此直接打开 `file://` 页面也不需要请求 JSON。导出保留全部实体、ID、正文、图片引用和版本关系，不导出 SQLite 的本机路径等构建元信息。

发布静态文件时只需复制：

```text
index.html
web/
data/card_images/
```

必须保留相对目录；不用复制 YAML、Python、SQLite 或历史管理页。Hash 路由不要求静态空间提供地址重写。无需外部字体、CDN或网络接口；小程序平台接入由用户后续实测，本轮不作平台兼容承诺。

页面自动按视窗宽度排版，无需切换手机/电脑模式。手机验收采用扣除宿主底部界面后的可用视窗432×820，以及更窄/更短的视窗；页面不固定整屏高度，允许正常纵向滚动。默认宿主提供缩短后的视窗，不额外留下固定空白。若宿主底部导航覆盖页面而非缩短页面，可设置根CSS变量`--host-bottom-inset: 80px`（数值按实际遮挡高度），为正文、弹窗和气泡保留空间。浏览器安全区通过`env(safe-area-inset-*)`处理。
